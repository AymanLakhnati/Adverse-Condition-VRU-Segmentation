# Transformer Segmentation of Vulnerable Road Users in Adverse Conditions

MAAI901 applied vision transformer project by Ayman Lakhnati.

This project studies person, rider, and bicycle segmentation across fog, nighttime, rain, and snow in the official ACDC benchmark. It implements memory-bounded inference for the official HRDA and MIC(HRDA) MiT-B5 checkpoints, the original weakest-condition hypothesis, and a separately identified supervised DINOv3 segmentation-head experiment.

Code, measured evaluation outputs, technical report, and presentation are being assembled. Published benchmark scores will be distinguished from locally executed results. Raw ACDC data and foundation checkpoints are downloaded from their official sources and excluded from this repository.

# Prespecified modern-transformer segmentation extension

Protocol fixed on 25 October 2026 before examining local ACDC validation scores. This experiment studies road-user semantic segmentation using only the prescribed ACDC splits.

The original hypothesis concerns the released HRDA and MIC(HRDA) checkpoints. This separate experiment applies the recent DINOv3 ViT-S/16 model family and trains a new target-supervised segmentation head on ACDC training labels. The settings differ in supervision, pretraining and architecture, so it cannot isolate a transformer architecture effect or serve as a MIC-only ablation. DINOv3's 2025 model-family results motivate the backbone choice, but this simple classifier does not claim state-of-the-art segmentation performance.

Load `timm/vit_small_patch16_dinov3.lvd1689m`, enable dynamic input size, and freeze every encoder parameter. At 512-by-512 resolution, use the final normalized patch tokens from `forward_features`, excluding the one class token and four register tokens. Reshape the 1,024 remaining 384-dimensional vectors to a 384-by-32-by-32 feature map. Train a newly initialized 1-by-1 convolution from 384 features to 19 Cityscapes-compatible classes, totaling 7,315 parameters. Bilinearly upsample its logits to the crop size with `align_corners=False`.

Before the final fit, tune the head's learning rate using only the official **training** partition. Within each weather condition, conservatively merge GoPro chapter directories into recording families: `GOPR0376`, `GP010376` and `GP020376`, for example, all become `recording_0376`. Retain original directory names in both manifests. Unknown naming conventions retain their complete names. Shuffle recording families with seed 42, then use dynamic programming over attainable image counts to choose the nonempty proper subset nearest 20% of that condition's training frames. Require at least one fitting family and one development family per condition. Equal-distance count ties favor more development images; equal-count subset ties favor the lexicographically earliest family-index tuple in the seeded ordering. Neither labels nor measured results enter this split. Save the actual family IDs, chapter aliases and image counts. Few large recording families may produce a fraction substantially different from 20%; report the actual split rather than assuming an 80/20 ratio. Never move individual frames or chapter aliases across these groups. This conservative grouping reduces recording leakage but does not prove geographic or scene independence. The official 406-image validation split and test images do not participate in this search.

Compare learning rates 0.0003, 0.001 and 0.003, using AdamW with weight decay 0.01 and one fitting epoch per trial. Reset every trial to the same fresh seed-42 head initialization and the same shuffled image/crop/flip random sequence. Train on random 512-by-512 crops with horizontal flip probability 0.5. Score one fixed center crop per development image, without flipping or selecting crops from their labels. Select the highest pooled person/rider/bicycle mean IoU, breaking exact ties in favor of the lower learning rate. If a trial's VRU mean has an undefined class union, it is ineligible. Only if all three VRU means are undefined, use the predeclared fallback of mean IoU over defined class unions and explicitly report that limitation. This center-crop proxy and small learning-rate grid are practical tuning choices, not an exhaustive optimization or a substitute for full-image validation.

Discard every trial's learned weights. Reinitialize the head from the same fresh seed-42 state, verify the encoder and initial head hashes, verify the complete training ID set and image/label content hashes against tuning, and fit all 1,600 adverse-weather ACDC training images for five fixed epochs, batch size four, shuffled each epoch. Use the selected learning rate, held fixed throughout the final fit, and AdamW weight decay 0.01. Each occurrence uses one random 512-by-512 crop and synchronized horizontal flip probability 0.5. Normalize RGB using ImageNet means and standard deviations. Optimize cross entropy, ignore label 255, and use no class weights. Keep the backbone in evaluation mode with no gradient tracking. No **official-validation** tuning, early stopping or checkpoint selection is permitted. A partial `--limit` run or changed epoch/batch settings must be explicitly distinguished from this full protocol.

Evaluate the final fixed-epoch head on the same 406 adverse validation images. Preserve each image's original resolution, infer 512-by-512 tiles at stride 384 with border-aligned final windows, bilinearly upsample tile logits and average overlaps before argmax. Predict all 19 classes. Report the original person's, rider's and bicycle's per-class IoU and the same primary VRU aggregation, alongside all-class metrics, in an explicitly labeled supervised-extension table.

Save a small head checkpoint, the exact encoder state SHA256, source model configuration, package versions, training IDs with image/label hashes, sampled crop coordinates and flips, per-step losses and gradient norms, actual duration and peak GPU allocation. Verify the encoder's parameters and buffers remain byte-identical. Do not distribute foundation weights or dataset images. The stride-16 representation and linear decoder can lose small road-user detail, and no result is guaranteed before evaluation.

Synthetic-label smoke tests establish shape, gradient and memory feasibility only. They are not dataset training or evaluation results.

Primary sources: [DINOv3 paper](https://arxiv.org/abs/2508.10104), [timm checkpoint and configuration](https://huggingface.co/timm/vit_small_patch16_dinov3.lvd1689m), [official ACDC dataset](https://acdc.vision.ee.ethz.ch/).
